### 정의
**Jakob's Law**는 사용자가 대부분의 시간을 다른 사이트에서 보내기 때문에, 새로운 인터페이스에서도 기존에 익숙한 디자인과 패턴을 기대한다는 UX 원칙이다.

### 주요 포인트

- **기대 일치성**: 익숙한 UI는 학습 시간을 줄이고 신뢰도를 높인다  
- **인지적 효율성**: 새로운 학습 부담 없이 즉시 사용 가능하게 함  
- **패턴 기반 예측**: 기존 경험에 따라 행동을 예측하고 반응하려는 경향

### 실무 적용

- **기본 UI 컴포넌트 사용**: 네비게이션 바, 햄버거 메뉴, 로그인 흐름 등은 통상적 형태 유지  
- **경쟁 서비스 조사**: 사용자가 자주 사용하는 유사 서비스의 UI와 흐름을 참고해 설계  
- **기대 흐름 보존**: 새롭고 창의적인 방식보다 익숙한 행동 경로를 우선적으로 고려

### 참고 사례

- **전자상거래 플랫폼**: 장바구니, 결제, 주문 확인 흐름은 대부분 유사하게 설계됨  
- **모바일 앱 네비게이션**: 하단 탭바 구성은 소셜미디어, 금융, 커머스 앱에서 공통적으로 사용


혁신은 익숙함을 기반으로 설계될 때 사용자에게 받아들여진다. UX 설계의 핵심은 사용자의 기존 행동 모델을 존중하는 데 있으며, 예측 가능한 사용 경험은 학습보다 우선한다.
