### 정의
**Paradox of the Active User**는 사용자가 시스템을 학습하기보다 즉시 목표를 달성하려는 경향 때문에, 더 나은 사용 방법이 있음에도 비효율적이고 비직관적인 경로를 고수하는 현상을 말한다.

### 주요 포인트

- **목표 지향성 우선**: 사용자는 인터페이스를 이해하려 하기보다 당장 원하는 결과를 얻는 데 집중  
- **학습 회피 경향**: 튜토리얼, 가이드, 설명서를 건너뛰고 시행착오를 통해 문제를 해결하려 함  
- **비효율 유지 가능성**: 비효율적인 사용 패턴이 습관화되어 최적 경로로의 전환이 어려워짐

### 실무 적용

- **학습 없는 사용 흐름 설계**: 초기 사용자가 별도 학습 없이도 과업을 수행할 수 있게 구성  
- **행동 유도형 UI 제공**: 시각적 강조, 순차 안내, 자동 포커싱 등을 통해 자연스럽게 사용 유도  
- **컨텍스트 내 피드백**: 작업 중간에 적절한 피드백과 제안을 제공하여 습관적 사용 방식 교정

### 참고 사례

- **툴팁 기반 안내**: 작업 흐름 중 필요한 시점에만 간단한 팁을 제공  
- **기능 축소 초기화면**: 최소 기능만 노출해 사용자가 핵심 흐름을 먼저 경험하게 유도


UX 설계는 사용자가 배우기를 원하지 않는다는 전제에서 출발해야 한다. 학습이 아닌 사용 중심의 흐름을 구축하고, 사용 과정 안에서 자연스럽게 최적의 방식으로 유도하는 전략이 필요하다.
