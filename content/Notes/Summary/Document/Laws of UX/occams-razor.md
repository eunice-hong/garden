### 정의
**Occam's Razor**는 어떤 문제에 대해 여러 가지 설명이나 해결책이 있을 때, 가장 단순한 것이 진실일 가능성이 높다는 원칙이다. UX 설계에서는 불필요한 복잡성을 제거하고 본질적인 기능에 집중하는 전략으로 활용된다.

### 주요 포인트

- **단순성 우선**: 기능이나 구성 요소가 적을수록 오류 가능성도 낮고 사용성도 높음  
- **설명 최소화**: 인터페이스가 직관적이라면 별도의 설명 없이도 사용 가능해야 함  
- **복잡성 제거**: 복잡한 설정, 옵션, 흐름은 필수 요소가 아닌 이상 제거하거나 축소

### 실무 적용

- **기능 미니멀 설계**: 사용자가 자주 사용하는 핵심 기능 위주로 화면 구성  
- **정보 계층 간소화**: 중첩된 메뉴나 다단계 네비게이션 대신 평면적이고 명료한 구조 채택  
- **단일 목적 중심 UI**: 한 화면이 여러 역할을 하지 않도록 주 기능에 집중

### 참고 사례

- **검색 UI**: 단순한 입력창과 버튼만으로 작동하며 추가 필터는 필요할 때만 노출  
- **모바일 앱**: 기본 기능 중심의 심플한 구조로 사용자의 빠른 적응 유도


단순함은 미니멀한 미학이 아니라 실용적 설계의 핵심이다. UX 설계는 사용자의 복잡한 행동을 통제하려 하지 말고, 단순한 선택만 허용하되 그 선택이 충분히 의미 있도록 구성해야 한다.
