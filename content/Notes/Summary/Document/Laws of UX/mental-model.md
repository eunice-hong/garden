## Mental Model

### 정의
**Mental Model**은 사용자가 시스템, 제품, 인터페이스의 동작 방식에 대해 머릿속에 형성하는 인지적 구조 또는 예상 모델을 의미한다. UX 설계는 이 모델과 실제 시스템 작동 방식의 정렬을 통해 효율성과 만족도를 극대화해야 한다.

### 주요 포인트

- **기대와 실제 간의 일치**: 사용자의 기존 경험과 예상이 실제 시스템 작동 방식과 일치할수록 사용성 증가  
- **오류 발생 최소화**: 기대와 시스템 간 괴리가 클 경우 혼란, 실수, 학습 비용 증가  
- **빠른 습득 가능성**: 기존에 익숙한 패턴을 차용하면 새로운 시스템도 더 빠르게 이해됨

### 실무 적용

- **비유적 인터페이스 사용**: 실제 객체와 유사한 버튼, 아이콘, 동작을 통해 직관적 사용 유도  
- **사용자 리서치 기반 설계**: 대상 사용자군의 기존 경험, 기대, 습관을 분석하여 설계 반영  
- **모델 충돌 최소화**: 기존 시스템과의 차이가 클 경우 명확한 설명, 피드백, 학습 경로 제공

### 참고 사례

- **휴지통 아이콘**: 파일 삭제 기능을 실제 쓰레기통 이미지와 동작으로 연결  
- **온라인 쇼핑몰 장바구니**: 오프라인 구매 경험과 동일한 흐름(담기 → 결제 → 배송)을 유지

### 결론

UX 설계는 기능 구현 이전에 사용자의 사고방식과 상호작용 모델을 이해하는 데서 출발해야 한다. 시스템이 사용자의 머릿속에 있는 모델을 따를 때, 진정한 직관성과 효율성이 구현된다.
